## Corrections or packaging checks

1. **Depenetration prefix provenance needs retention.** The new header expands the Part6 opaque prefix into `flags00`, `vector04` and `contacts10`. I independently decoded leaf `0x145E38860` directly from the verified PE: it tests DWORD+0 masks8/0x15, compares pointers+0x10/+0x18, reads floats+4/+8/+0xC, conditionally reads+0x28/+0x2C/+0x30 if byte+0x34==1, and writes MoveRequest+0x48/+0x4C/+0x50. RET is `0x145E388DA`; this leaf lacks a covering `.pdata` entry. This supports flags and vector access, but does not alone prove that +0x20 is a vector capacity or that the pointer range holds contact records. Include that leaf's export/evidence and either independently substantiate the header/range element interpretation or keep those fields opaque. The prior final checkpoint mentions the leaf, but its corresponding assembly export was absent when reviewed.
2. **Standalone Ghidra setup must be reproducible.** `run_targeted_headless.py` exposes tool/project overrides but assumes an existing mapped program. At review time, `WORK/ghidra/README.md` does not show how to create the PE-to-RVA mapped file and import it into a fresh project, although root README says the setup is described there. Include the previous mapping script and a verified import command, or state that the earlier project archive is a prerequisite.
3. **Finish referenced deliverables before packaging.** At review time root README/report reference `EVIDENCE.csv`, `FUNCTION_INDEX.csv`, `PORT_STATUS.csv`, `VERIFICATION_REPORT.md` and `CALL_GRAPH.dot` before those files exist. These are expected ongoing work; validate links/manifests on the final staged archive.
4. **Keep oracle distinctions explicit.** Reconstructed C++ residual-reference agreement is not independent executable evidence. Glide fixtures use synthetic/native-dependency inputs and Linux trig, so arithmetic agreement does not establish Windows CRT/LUT identity. Current root prose correctly makes these distinctions; preserve them in consolidated text and final test tables.
